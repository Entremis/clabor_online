# Общее облако Клабора

Реализовано 9 сентября 2026 года. Приложение: https://clabor-online.vercel.app. API: https://clabor-cloud.rumelets75.workers.dev.

## Для игроков

Один логин и пароль — одна компания. Все устройства под этим аккаунтом видят общих игроков, составы, текущую игру, историю и статистику. Другая компания регистрируется отдельно. Профили игроков не требуют отдельных паролей.

При первом входе можно перенести прежние сохранения устройства. Если перенос пропущен, он доступен в «Аккаунте». Исходная локальная копия сохраняется; повторный перенос в другую компанию заблокирован. Старые записи без связи с профилями доступны в истории, но не приписываются игрокам по совпадению имени.

После входа приложение работает без сети. Очередь сохраняется в IndexedDB и переживает перезагрузку. При появлении сети и открытии приложения обмен возобновляется; на открытом экране обновления проверяются каждые 30 секунд. Фоновая работа закрытого приложения не требуется. Перед переходом на другой телефон дождитесь статуса «Всё сохранено в облаке».

При конкурирующих правках одной записи пользователь выбирает вариант в «Аккаунте». Обе версии дополнительно сохраняются в локальной резервной копии. Очистка данных сайта удаляет эту копию и ещё не отправленные изменения. Выход из аккаунта их не удаляет; следующий вход в тот же аккаунт продолжает отправку. Срок сессии — 30 дней, повторный вход не стирает очередь. Восстановления забытого пароля через почту пока нет.

## Реализация

- Отдельные Worker `clabor-cloud` и D1 `clabor-data`. Исходники, сервер и данные Нагады не изменялись; использована только её схема Worker + D1 + локальная IndexedDB.
- Все записи и запросы привязаны к владельцу из проверенной сессии. Сессии случайные, в базе хранится хеш токена; выход отзывает текущую сессию. Ограничены попытки входа и регистрации.
- Пароли: PBKDF2-SHA256, случайная соль, 100 000 итераций и HMAC-SHA256 с отдельным секретом `PASSWORD_PEPPER` в Cloudflare. Опубликованный Workers отклонил 600 000 итераций, хотя локальный workerd их принимал. Секрет не находится в D1 или Git. Его нельзя менять без процедуры смены паролей: существующие пароли перестанут проверяться.
- Данные передаются отдельными записями с серверными версиями. D1 атомарно проверяет исходную версию аккаунта и применяет пакет. Трёхстороннее сравнение объединяет независимые изменения и сохраняет конфликты одной записи. Повтор операции с тем же ID не дублирует результат. Удаления передаются как постоянные отметки.
- Очередь, исходные версии и запрос с неизвестным результатом хранятся локально отдельно для каждого аккаунта. Переключение аккаунта блокирует старые вкладки. Web Locks ограничивают параллельные отправки вкладок; сервер дополнительно проверяет версии.
- История и профили являются источником статистики. Сервер не хранит независимо изменяемые счётчики побед.

## Разработка и публикация

```sh
npm ci
npm test
npm run build
npm run cloud:migrate
npm run cloud:deploy
```

Vercel публикует `dist` из `main`, настройка находится в `vercel.json`. Публичный адрес API задан в `cloud_config.js`; при сборке его можно заменить переменной `CLABOR_API_URL`.

Для локального сервера примените миграции командой `npx wrangler d1 migrations apply clabor-data --local --config cloud-worker/wrangler.jsonc`. Создайте игнорируемый `cloud-worker/.dev.vars` с отдельным тестовым `PASSWORD_PEPPER` длиной не менее 64 символов, запустите `npm run cloud:dev`. Соберите приложение с `CLABOR_API_URL=http://127.0.0.1:8787`, затем запустите preview на порту 4190 или 4191. Эти адреса явно разрешены в CORS. Локальный D1 не изменяет рабочую базу.

Секрет рабочего сервера задаётся один раз через `wrangler secret put PASSWORD_PEPPER --config cloud-worker/wrangler.jsonc`. Не сохраняйте его в репозитории и не запускайте повторную генерацию для уже используемых аккаунтов. Для нового домена приложения дополните точный список `ALLOWED_ORIGINS` и переопубликуйте Worker; произвольные Preview-адреса не разрешены.

## Проверки и стоимость

59 автоматических тестов: игровые правила, миграции и транзакции, независимые клиенты, смена аккаунтов, конфликты, реванш, повторы запросов и пагинация. В двух независимых браузерных сеансах проверены общие профили, состав, игра, офлайн-запись с перезагрузкой, восстановление обмена, общая история и статистика. Рабочий API проверен временными аккаунтами: регистрация, вход, CORS, общие записи, изоляция компаний, повтор запроса, отклонение устаревшей записи и выход.

Платные услуги не подключались. Нагрузка небольшой компании ожидается в пределах бесплатных квот, но это не безлимитный сервис. Текущие ограничения: [Workers](https://developers.cloudflare.com/workers/platform/limits/) и [D1](https://developers.cloudflare.com/d1/platform/pricing/). При недоступности сервера очередь остаётся локально до восстановления связи.
